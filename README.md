# AWS E-Commerce Data Lake and Analytics

A data engineering project that combines Python-based ETL with Amazon S3, AWS Glue, and Amazon Athena to clean e-commerce order data and perform cloud-based analytics.

## Project Overview

This project demonstrates how raw e-commerce order data can be transformed into structured datasets and analyzed using AWS services.

The Python ETL pipeline runs locally and uses Pandas to clean and validate the data, calculate order revenue, and generate daily sales summaries. The resulting Parquet files are uploaded to Amazon S3, cataloged using AWS Glue crawlers, and queried with Amazon Athena.

## Dataset

The sample dataset contains 15 e-commerce order records across eight dates, from October 1 to October 8, 2026.

The dataset includes:

- Order ID
- Order date
- Customer ID
- Product
- Category
- Quantity
- Unit price
- City

The ETL pipeline generates a `total_amount` column by multiplying quantity by unit price.

## ETL Process

The Python pipeline performs the following operations:

1. Reads the source CSV file.
2. Standardizes text fields by removing unwanted whitespace.
3. Converts dates and numeric columns to appropriate data types.
4. Removes invalid records and duplicate rows.
5. Filters invalid quantities and negative unit prices.
6. Calculates total order amounts.
7. Generates a cleaned orders dataset.
8. Aggregates daily revenue, order count, and quantity sold.
9. Exports the processed datasets in CSV and Parquet formats.

## AWS Implementation

### Amazon S3

Stores the raw source data and the processed and curated Parquet datasets in separate prefixes.

### AWS Glue

Glue crawlers discover the Parquet schemas and register tables in the `ecommerce_analytics` database.

The current catalog contains:

- `processed` — cleaned order-level data
- `curatedcurated` — daily sales summary data

### Amazon Athena

Athena queries the cataloged datasets using SQL without requiring a database server to be provisioned.

## Analytics and SQL Queries

### 1. Revenue by City

```sql
SELECT
    city,
    SUM(total_amount) AS total_revenue,
    COUNT(*) AS total_orders
FROM processed
GROUP BY city
ORDER BY total_revenue DESC;
```

### 2. Revenue by Product Category

```sql
SELECT
    category,
    SUM(total_amount) AS total_revenue,
    SUM(quantity) AS units_sold,
    COUNT(*) AS order_count
FROM processed
GROUP BY category
ORDER BY total_revenue DESC;
```

### 3. Daily Sales Summary

```sql
SELECT *
FROM curatedcurated
ORDER BY order_date;
```

## Setup and Execution

### Prerequisites

- Python 3.10 or later
- Git
- An AWS account for the cloud components
- Appropriate AWS permissions for S3, Glue, and Athena

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd aws-ecommerce-data-lake
```

### 2. Create a virtual environment

On Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the ETL pipeline

Ensure `orders.csv` is in the project root, then run:

```bash
python etl_pipeline.py
```

The script generates cleaned CSV and Parquet files and the daily sales summary under `output/`.

### 5. Upload datasets to Amazon S3

Upload `cleaned_orders.parquet` to the `processed/` prefix and `daily_sales.parquet` to the `curated/` prefix of your S3 bucket.

Upload the original CSV to the `raw/` prefix.

### 6. Configure AWS Glue

Create or run Glue crawlers for the processed and curated prefixes. Configure them to use the `ecommerce_analytics` database.

### 7. Query with Athena

Configure an S3 query-results location in Athena and execute the SQL examples above.

**Note:** The Python ETL script currently runs locally. Uploading files to S3 and running Glue and Athena are separate steps in the current implementation.
